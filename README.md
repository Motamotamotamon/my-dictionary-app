# My Dictionary App 📘

A personal English dictionary app built with Next.js and Prisma.  
You can add, search, edit, and delete your own vocabulary.

## Features

- Add new words with meaning, part of speech, definition, and example
- Search by word or meaning
- Edit meaning and example inline
- Delete words
- Persistent storage with database (Prisma)

## Tech Stack

- Next.js (App Router)
- React
- Prisma
- SQLite (or your current DB)

## Dictionary data

Definitions and pronunciation metadata are provided by the [Datamuse API](https://www.datamuse.com/api/), using Wiktionary and WordNet data. Pronunciation audio is not supplied by this endpoint. Exact word matches are required; spelling suggestions are not displayed as definitions. Datamuse has announced an API-key requirement for 2027; review their usage terms before then.
